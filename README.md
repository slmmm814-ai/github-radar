# رادار GitHub+ (الإصدار 2)

تطبيق أندرويد (Kotlin + Jetpack Compose) واجهته عربية بالكامل (RTL). خمسة تبويبات + إعدادات.

## التبويبات
1. **اكتشف**: يجمع من مصادر تختارها: GitHub Trending (يومي/أسبوعي/شهري + لغة)، جديد حسب 8 مجالات، Hacker News، Lobsters.
   - تقييم 0-100: سرعة النمو، نمو حقيقي منذ آخر فحص (لقطات محلية)، النشاط، الترخيص، الأرشفة، صحة التفرّعات، تحذير من النجوم المضخّمة، نقاش المجتمع.
   - "تقرير اليوم": ملخص صباحي عربي.
2. **ابحث**: بحث مستودعات (لغة، حد أدنى للنجوم، ترتيب) وبحث مطورين ومنظمات.
3. **حلّل**: أدخل مستودعًا أو مطوّرًا أو مستودعين للمقارنة.
   - حقائق: اللغات، المساهمون وتركّزهم، التزامات آخر 4 أسابيع، آخر إصدار.
   - وضع التحليل (جرّبه/راقبه/تجاهله) ووضع التعلّم (شرح لمبتدئ + مشروع تطبيقي).
   - تحليل ملف مطوّر: تخصصه وأبرز أعماله.
   - مشاركة رابط مستودع من المتصفح إلى التطبيق تملأ الحقل.
4. **أمان**: أحدث ثغرات GitHub Advisories حسب الخطورة والنظام (npm, pip, Maven, Go, Rust...) مع تلخيص عربي.
5. **تابع**: مفضلتك مع آخر إصدار لكل مستودع وتلخيص عربي للإصدار.
6. **الإعدادات**: المفاتيح، المصادر، المجالات، التنبيهات اليومية (اكتشافات وإصدارات).

## خادم الرادار (اختياري)
مصدر خامس «خادم الرادار (GH Archive)» يكشف المستودعات المتسارعة من أرشيف GH Archive. الخادم في المجلد المنفصل `radar-server` (راجع README الخاص به). أدخل عنوانه ومفتاحه من الإعدادات.
ملاحظة: AndroidManifest يسمح بـ HTTP لتجارب الشبكة المحلية؛ أزل `usesCleartextTraffic` عند استخدام HTTPS في الإنتاج.

## البناء
1. افتح المجلد في Android Studio (Koala أو أحدث) ودع Gradle يزامن.
   إن طلب wrapper: `gradle wrapper --gradle-version 8.7`
2. شغّله على Android 8.0+.
3. من الإعدادات أضف توكن GitHub ومفتاح Claude API (اسم النموذج الافتراضي `claude-sonnet-5-5` قابل للتعديل).

## حدود يجب معرفتها
- **لم يُبنَ ولم يُختبر** في بيئة الإنشاء؛ أرسل نص أي خطأ يظهر عند البناء.
- لا يغطي كل GitHub (مئات الملايين من المستودعات): يغطي ما تكشفه المصادر أعلاه. GH Archive الكامل ضخم جدًا للهاتف ويحتاج خادمًا.
- Trending يُقرأ من صفحة HTML ولا يوجد API رسمي، فقد يتعطل إن غيّر GitHub تصميمها (تبقى المصادر الأخرى تعمل).
- بدون توكن GitHub: 60 طلبًا/ساعة للـ API العادي و10/دقيقة للبحث، فيقلّل التطبيق عدد المستودعات المجلوبة.
- المفاتيح في SharedPreferences غير مشفّرة. لا توزّع APK يحتوي مفاتيحك. استدعاءات Claude مدفوعة.
- نصوص README والإصدارات والنبذات تُرسل إلى Claude كبيانات فقط مع تعليمات بتجاهل أي أوامر داخلها.

## تطويرات لاحقة ممكنة
خادم صغير يجمع GH Archive ويقدّم API للتطبيق، قاعدة Room لحفظ السجل، تشفير المفاتيح، ويدجت للشاشة الرئيسية.
